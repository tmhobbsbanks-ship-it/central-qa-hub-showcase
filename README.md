# Central QA Hub

[Try the live demo](https://tiffany-hobbs-project-demos.v2khqp8nzc.chatgpt.site/#central-qa-hub)

I built Central QA Hub with Google Apps Script and Google Sheets to track audit assignments, reviewer progress, appeals, masked re-reviews, and monthly reporting.

## Try the workflow

1. Assign an unassigned sample audit and watch it move into review.
2. Start a masked re-review on the appealed case to see how an independent reviewer is assigned.
3. Record the decision, then filter the queue and check the updated totals.

The demo uses fictional cases and reviewers.
